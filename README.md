# Hello, I'm Camen

I build web applications and IoT systems — from simple prototypes to production-grade solutions.

---

## What I Do

I write code across the full stack, but my real interest lies in connecting the digital world with physical devices. Whether it's a REST API, a real-time dashboard, or an Arduino-based sensor network, I enjoy the challenge of making things work together seamlessly.

Over the years, I've worked with:

- **Backend:** Node.js (Express), Laravel, Python (Flask/Django)
- **Frontend:** React, Vue.js, and sometimes vanilla JS when it's enough
- **IoT:** Arduino, ESP8266/ESP32, Raspberry Pi, MQTT, WebSockets
- **Databases:** MySQL, PostgreSQL, MongoDB, Firebase
- **DevOps:** Docker, Nginx, basic cloud deployment (AWS/DigitalOcean)

I don't chase every new framework — I prefer stable tools that get the job done.

---

## How I Work

- I write clean, maintainable code with sensible documentation
- I test things properly (unit tests, integration tests, and real-world trials)
- I design systems with scalability in mind, even for small projects
- I communicate clearly — with clients, teams, or end users

I've built projects ranging from admin dashboards and e-commerce platforms to environmental monitoring systems and home automation controllers. Each project taught me something new — about code, about users, and about problem-solving.
